# My First GitHub Project

A beginner-friendly project created to learn and practice Git and GitHub.

## About the Project

This project contains a simple Python program that asks the user for their name and displays a welcome message along with a learning message.

## Technologies Used

- Python
- Git
- GitHub
- Visual Studio Code

## Git & GitHub Concepts Practiced

- Repository
- README
- Clone
- Commit
- Push
- Pull
- Branch
- Merge
- Pull Request

## What I Learned

Through this project, I learned how to create a repository, clone a project, make changes, commit and push files, work with branches, merge changes, and create a pull request.

## Project Goal

The goal of this project is to gain practical knowledge of Git and GitHub through hands-on practice.

## Conclusion

This project helped me understand the basics of version control and how GitHub can be used to manage and collaborate on projects.
